# GTA:LCS PortMaster 1.0.0

The first public release is ready for AArch64 PortMaster handhelds.

Verified in community testing:

- gameplay through the first story mission;
- smooth performance without observed lag or stutter;
- PlayStation-position controls;
- autosave and manual save loading after a full restart;
- sound effects and radio music; and
- clean installation from user-supplied Android files.

The package contains no Rockstar APKs, libraries, WADs, saves or logs. Users
must supply the matching Android 2.4.379 ARM64 files from their own legally
purchased installation.
