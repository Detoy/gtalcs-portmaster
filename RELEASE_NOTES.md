# GTA:LCS PortMaster 1.1.0

Version 1.1.0 is a packaging and documentation update to the community-tested
public release. The gameplay runtime is unchanged.

- Added the MIT licence to the repository and downloadable ZIP.
- Added an explicit package version file.
- Clarified secondary-audio extraction from a rooted Android phone.
- Strengthened release integrity, privacy, version and licence checks.
- Polished installation, support and compatibility documentation.

The package still contains no Rockstar APKs, libraries, WADs, saves or logs.
Users must supply the matching Android 2.4.379 ARM64 files from their own
legally purchased installation.
