# Security and private files

Please use GitHub's private vulnerability-reporting feature for security
problems. Ordinary compatibility bugs can use the public issue template.

Never upload or commit:

- APK, APKS, APKM or XAPK files;
- WADs, OBBs or extracted shared libraries;
- saves, userdata or logs containing personal paths;
- cryptocurrency recovery phrases, private keys or passwords.

The project will never ask for a wallet recovery phrase or private key.
